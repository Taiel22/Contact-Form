# 📩 Contact Form

A clean, modern, and responsive **Contact Form UI** built with HTML5 and CSS3.

The project provides a dark-themed contact form with a green accent color, intuitive icons, responsive input fields, and a contact-information section.

It is designed as a simple front-end project that can be integrated with a backend, email service, or form-handling API in the future.

---

## ✨ Features

- 📩 Contact form interface
- 👤 Name field
- 📧 Email field
- 📱 Optional phone field
- 🏷️ Subject field
- 💬 Message textarea
- 🚀 Send Message button
- 📍 Contact address section
- 📧 Contact email section
- ☎️ Contact phone section
- 🎨 Modern dark UI
- 🟢 Green accent theme
- 🔍 Input focus effects
- ✨ Smooth hover animations
- 🎭 Font Awesome icons
- 📱 Responsive layout
- ⚡ Lightweight and fast
- 🚫 No framework required
- 🚫 No JavaScript dependency
